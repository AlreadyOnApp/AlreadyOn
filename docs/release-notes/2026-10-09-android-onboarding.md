## Features

- Connect phones, tablets and Google TVs to a server on your home network without typing its address. Previously connected servers appear first; automatic discovery searches for up to 30 seconds.
- Sign in with your username and a personal pairing PIN instead of your account password. Each user can set or remove their own PIN in Admin Settings.
- Give your server a recognizable name during setup, or change it later in Server Settings, so it is easier to identify when connecting a device.
- Watch on Google TV with a guide and compact player. Selecting a channel opens fullscreen playback; Left/Right changes channels, Up/Down opens controls, and Back returns to the guide.

## Improvements

- Swipe up for a higher channel or down for a lower channel on phones and tablets while watching fullscreen, in either portrait or landscape.
- Show or hide entered PIN digits using the eye button on phone/tablet sign-in and in WebUI Admin Settings.
- Manage TV Pairing Pin beneath the password fields, with a Remove Pin button when one is configured. Server Name help is available through More Info.
- TV setup screens and the PIN keypad are centered. Focus moves to the username field, then the PIN; profile selection starts on the first profile and the guide selects the current airing.
- Google TV account menus offer Switch Profile and Sign Out.

## Bug fixes

- Fullscreen channel changes preserve the player orientation, mute state, video quality and subtitle settings.
- The AlreadyOn logo no longer captures taps or remote focus on Android devices.
