## Features

- Configure the current TV profile’s name, icon, PIN, time format, audio language and subtitle defaults with the remote in a full-screen Profile Settings page.
- See a brief navigation tutorial after selecting a TV profile for the first time.

## Improvements

- Browse a compact four-row TV guide with smoother scrolling, two-line programme cards and details that follow the selected programme.
- See centered startup branding on Android phones and TVs while the app prepares content.
- Open the profile menu from the mini-player with Switch Profile selected, and return to the mini-player with Back.
- Find video qualities in descending resolution order and preferred audio and subtitle languages first.
- Save TV profile settings without leaving the page, retain focus on the current category, and see a confirmation below the action buttons that clears when switching categories.

## Bug fixes

- Navigate TV programme cards horizontally and vertically without losing focus, skipping commercials and aligning guide headers to hour and half-hour boundaries.
- Start fullscreen playback unmuted and navigate visible player controls without accidentally changing channels.
- Select Play/Pause whenever player controls appear and focus the current value in quality, audio and subtitle menus.
- Use Back to return to the watched programme, select the mini-player, then exit to the TV home screen.
- Keep native sign-in active until signing out or revoking all device sessions from the WebUI.
